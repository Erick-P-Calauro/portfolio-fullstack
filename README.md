# Portfólio de Desenvolvedor

Este repositório contém minha implementação do desafio prático "Portfólio Dev" do módulo "Avançando no HTML e CSS" da Formação Full-Stack da Rocketseat. 

Veja o resultado em : https://erick-p-calauro.github.io/portfolio-fullstack.

## Quais conhecimentos foram demandados ?

O projeto foi inicialmente desenvolvido utilizando exclusivamente HTML e CSS. O objetivo inicial desse desafio foi colocar em prática tópicos avançados em CSS, principalmente variáveis, pseudo-classes, pseudo-elementos, Flexbox e Grid. 

O projeto será customizado para melhor se adequar ao meu perfil profissional e poderá englobar conhecimentos obtidos posteriormente.

## Créditos

O design do desafio foi fornecido como material pela Rocketseat, com customizações feitas por mim.
A implementação é de minha autoria.
